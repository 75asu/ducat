what it is

Every provider, one signal

Per-provider adapters call each billing API and normalize to a common FOCUS-shaped record , so whole-account cloud + SaaS + AI cost finally lands in one place.

Two metrics, one truth

ducat_cost_usd (net) and ducat_list_cost_usd (list), labeled {provider, billing_account, service, currency}. The gap between them is what your commitments save.

Not a platform

No database, no UI, no operator. Storage and dashboards are the Prometheus + Grafana you already have; ducat only does the fetch-and-normalize.

Two run modes

serve exposes /metrics for Prometheus to scrape; run does a one-shot remote_write of dated samples, the right shape for a daily bill on CI/cron.
